# Как выпустить версию RenDit UI

Работа идёт в ветке `main` — каждый пуш проверяет GitHub (биом, тесты, сборка сайта и готового CSS).
Версия — это тег `vX.Y.Z`: по нему GitHub собирает релиз с архивом `rendit-ui.zip` и готовым CSS, а сайт
показывает её во вкладке «Обновления» с кнопкой «Скачать».

## 1. Пишите изменения сразу

Каждое изменение — строка в `CHANGELOG.md` в разделе `## [Unreleased]`, в своей группе:

```md
## [Unreleased]

### Добавлено
- Компонент «Модалка»: …

### Изменено
- …

### Исправлено
- …
```

Группы: **Добавлено**, **Изменено**, **Исправлено**, **Удалено**, **Безопасность**. Пункт — что увидит человек,
а не что поменялось в коде. Можно `код` и **жирный**.

## 2. Выберите номер

`большая.новая.исправление` ([semver](https://semver.org/lang/ru/)):

- **исправление** (0.2.0 → 0.2.1) — только исправления;
- **новая** (0.2.x → 0.3.0) — новые классы, токены, страницы, компоненты; старое работает как раньше;
- **большая** (0.x → 1.0.0) — переименования и удаления, которые ломают чужую разметку.

## 3. Выпустите

```bash
npm run release -- 0.3.0
```

Скрипт (`scripts/release.mjs`): переносит `[Unreleased]` в `## [0.3.0] — дата`, ставит версию в
`package.json`, пересобирает готовый CSS (`dist/`), делает коммит «Версия 0.3.0» и тег `v0.3.0`. Затем:

```bash
git push --follow-tags
```

GitHub (`.github/workflows/release.yml`) соберёт архив и создаст релиз с описанием из CHANGELOG. Готовый CSS
этой версии сразу доступен с CDN:
`https://cdn.jsdelivr.net/gh/Relux777/ui@v0.3.0/dist/rendit-ui.min.css`.

## Что в архиве

```
rendit-ui/
├── rendit-code/          движок RenDit Code и расширение VS Code
├── src/assets/scss/      RenDit SCSS
├── rendit.config.mjs     настройки движка
├── dist/                 готовый CSS: rendit-ui.css и rendit-ui.min.css
├── README.md · CHANGELOG.md · LICENSE
```
