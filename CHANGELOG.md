## [0.2.0] — 2026-10-28

### Добавлено
- Логотип RenDit UI — знак «Layers»: компонент `<RenDitMark />` / `<RenDitLogo />`, фавикон, иконка для iPhone, превью для соцсетей, манифест.
- Страница `/logos` со всеми вариантами логотипа; шапка и подвал сайта вынесены в общие компоненты.
- Заголовки страниц, описание и цвет панели браузера в метаданных.
- Шапка сайта `src/components/Header`: логотип и версия, ссылки по центру, язык (заглушка) и тема справа, мобильное меню; выпадающие списки на Popover API без JS.
- RenDit Code: в произвольных свойствах `--имя` остаётся именем (`[anchor-name:--menu]`), а не превращается в `var()`.
- Нижнее меню `src/components/NavBar` — «Жидкое стекло» из ozon (линза, жесты, тени): Главная, Начало, Справка, Меню; выезжает снизу вместе со сжатием шапки. Справа — быстрое меню на стрелке: язык и размер шрифта (заглушки), тема, сколько прочитано.
- Страницы `/docs` (Справка) и `/docs/install` (Начало), оглавление раздела — `src/app/docs/_nav.ts`.
- Размер текста на сайте (быстрое меню у NavBar → кнопка шрифта → строка 13…18): выбранный размер хранится в localStorage и ставится скриптом до первой отрисовки. RenDit Code умножает `font-N`, `font-N/LH` и `leading-N` в px на `--text-scale` (по умолчанию 1), базовый шрифт — тоже; свои значения (`text-[18px]`) не масштабируются.
- Быстрое меню: пункты появляются по очереди снизу вверх на пружине, исчезают быстро; под кнопкой шрифта — текущий размер. Строка размеров стоит рядом с таблеткой, а не внутри неё (внутри чужого backdrop-filter размытие не работало): фон 70 % и blur 20.
- RenDit Code: `transition-[свойства]` — переход для своих свойств (`transition-[grid-template-rows,opacity]`).
- RenDit SCSS: класс `.spotlight` (`components/_spotlight.scss`) — «прожектор», тусклый свет за курсором; цвет — `--spotlight`.
- `/header`: вариант 13 «Две таблетки» — логотип и кнопки остаются на местах, каждый в своей таблетке с blur 12 и shadow-7.
- RenDit SCSS: класс `.liquid-glass` (`components/_glass.scss`) — «жидкое стекло» для плавающих панелей, без SVG-фильтров.
- «Как приложение» на iOS и Android: `viewport-fit=cover` (поля `env(safe-area-inset-*)` у шапки, нижнего меню и контейнера теперь работают), режим «На экран Домой» на iPhone (`apple-mobile-web-app-*`, прозрачная строка состояния), клавиатура Android сжимает страницу (`interactive-widget`), без «резинки» и pull-to-refresh у страницы, манифест с `id`/`scope`/`lang` и PNG-иконками 192 и 512 (обычная и maskable), плавная смена страниц (накладка `.route-enter`, 0,26 с, без анимации при «уменьшении движения»), номера телефонов не превращаются в ссылки.
- Тесты интерфейса `npm test` (node:test, TypeScript без сборки): пороги прокрутки, пункт меню по адресу, процент прочитанного, математика линзы, правила анимаций (стили компилируются sass); вместе с тестами RenDit Code.
- Браузерные тесты `npm run test:e2e` (Chrome / Edge без окна по CDP, без зависимостей; нужен запущенный сайт, адрес — `E2E_URL`): появление нижнего меню и его стекло по кадрам, переходы между страницами (меню не двигается и не накрывается), «назад», перезагрузка посреди страницы, логотип, поиск, размер шрифта, телефон.
- Поиск в шапке: лупа (или «/», Ctrl+K) раскрывает поле в таблетке, подсказки выпадают панелью и проявляются по очереди; ↑/↓, Enter, Esc; крестик закрывает и стирает запрос. Данные пока тестовые (`Search/items.ts`).
- RenDit SCSS: класс `.route-enter` (`components/_route-enter.scss`) — новая страница проявляется при переходе (тает накладка цвета фона), сама страница не становится прозрачной, и стекло внутри неё не ломается.
- «Справка» с тремя вкладками, как у HeroUI: **Установка и настройка** · **Компоненты** · **Обновления** (`components/DocsTabs`), у каждой вкладки свой layout (`app/docs/(getting-started)`, `docs/components`, `docs/releases`). Вкладки — тонкая капсула в стиле раскрытого поиска: по центру шапки (от 620px; подписи — от 1200px, после прокрутки — третья стеклянная таблетка), на телефоне — в начале страницы справки (уезжают с текстом и не закрывают контент). Выбранная вкладка — стеклянная подложка и залитая иконка.
- Окно быстрого доступа `components/QuickNav` (как «Быстрый переход» в ozon): кнопка в шапке справа от «Начать» и пункт «Меню» нижнего меню. На телефоне — лист снизу (смахивается вниз), с 620px — панель справа. Внутри: вкладки справки, «На этой странице» — разделы страницы с номерами (берутся из элементов с `data-toc`, раздел на экране подсвечен), все готовые страницы справки.
- RenDit SCSS: `.sheet` (`components/_sheet.scss`) — окно на `<dialog>` (фокус, Esc и недоступный фон — силами браузера), анимации на `@starting-style`; `.aura` — фон страницы: мягкое свечение цветов RenDit и сетка точек вверху, только градиенты; `.reveal` — блок проявляется при прокрутке (`animation-timeline: view()`, без JS, только прозрачность — якоря не сбиваются).
- Страница «Установка и настройка» (`/docs/install`) — только установка и настройка проекта. Выбор набора: платформа карточкой с логотипом и версией (**Next.js 15+** App Router, **React 18+** на Vite 6+, **Node.js 20+** без фреймворка, **HTML 5** без Node.js) и вопросы к ней переключателями iOS — язык (TypeScript / JavaScript), стили (SCSS / CSS), движок (RenDit Code / без движка), у HTML — скрипты (JavaScript / jQuery 3.6+). С движком — ещё вопрос «Редактор»: VS Code добавляет шаг «Поставьте подсказки в VS Code» (расширение RenDit Code IntelliSense, метка «рекомендуем»). Вопросов, которых у набора нет, не видно; шаги, имена файлов (`layout.tsx` / `layout.jsx`, `next.config.ts` / `.mjs`) и команды собираются под набор мгновенно, в браузере (`install/choice.ts` — модель выбора под тестом, `install/steps.tsx` — шаги). Набор запоминается и попадает в ссылку (`?stack=react&lang=js&styles=css&engine=none`), кнопка «Ссылка» копирует её. Карточка выбора — в 3D: наклоняется за курсором, по ней бежит цветной свет (как на boxicons.com); под каждым вопросом — что значит выбранный вариант; над шагами — сколько их и что понадобится (Node.js 20+ или только браузер); в шаге «Готово» — живой результат примера («Так это выглядит»). Команды npm · pnpm · yarn · bun (выбор запоминается); проверка; настройка проекта — карточками на отдельные страницы; что лежит в проекте — деревом папок; вопросы и ответы — «Перед установкой» (что такое RenDit Code, SCSS или CSS, можно ли без Node.js) и «Если что-то не так»; оглавление «На этой странице».
- RenDit SCSS: `.tilt` (`components/_tilt.scss`) — 3D-наклон карточки за курсором на пружине (углы — зарегистрированные `--tilt-x` / `--tilt-y`, их пишет компонент `components/Tilt`), по карточке за курсором бежит мягкий свет цветов RenDit `.tilt-light` (лиловое ядро, розовая и лаймовая дымка, лиловая кромка); только мышь, без наклона при «уменьшении движения».
- Страницы справки, вынесенные из установки: **Токены** (`/docs/scss/tokens`), **Цвета и тема** (`/docs/scss/colors`), **Варианты** (`/docs/code/variants`), **Конфиг** (`/docs/code/config`), **Команды** (`/docs/code/cli`), **VS Code** (`/docs/code/vscode`).
- Блоки документации (`app/_docs`): `DocHeader`, `Heading` (якорь + `data-toc`), `CodeBlock` со своей подсветкой кода (`highlight.ts`: JS/TS/JSX, JSON, CSS/SCSS, HTML, терминал — на сервере, без зависимостей и JS в браузере; цвета — токены `--code-*`), `Steps` (метки «по желанию» и «рекомендуем», живой результат под кодом), `Callout`, `Table`, `Files`, `FileTree` (дерево папок: значки по типу файла, линии к родительской папке, пояснения ровной колонкой, метки «точка входа», «не редактировать»), `LinkCards`, `InstallCommand`, `Toc`, `Accordion` (вопрос-ответ на `<details>`: открывается и закрывается плавно, на пружине, в том числе в Safari на iPhone; нажатие посреди анимации разворачивает её с того же места).
- Копирование — один отклик везде (блоки кода, команды установки, «Ссылка» на набор, SVG на `/logos`): значок на пружине сменяется галочкой, вокруг кнопки расходится зелёное кольцо, рядом выскакивает «Скопировано» (`app/_docs/copy-button.tsx`: `useCopy`, `CopyIcon`, `Copied`).
- Страница «Цвета» (`/docs/scss/colors`): как устроены цвета (палитра → токены → классы), 22 смысловых цвета в светлой и тёмной теме рядом с копированием класса, палитра 14 × 11 с копированием как `bg-`/`text-`/`border-`, конструктор класса цвета (что красим, цвет, непрозрачность, «всегда / при наведении / в тёмной теме» → превью в двух темах, класс и CSS), прозрачность, статусы и метки, готовые сочетания кнопок и карточек, градиенты, проверка контраста по WCAG в обеих темах, свои цвета. Новая страница «Тёмная тема» (`/docs/scss/dark`).
- Боковое меню справки: созданы все страницы — разделы с главной вынесены в «RenDit SCSS» (Текст, Отступы, Flex, Сетка .row, Grid, Рамки, Тени, Состояния, Адаптив, Слои), плюс «Устройство», стеки, «Классы», «Свои значения», «Редактор». Пока это заготовки с планом страницы (`docs/_stubs.ts`, `app/_docs/stub.tsx`).
- RenDit SCSS: `data-theme="light"` на любом элементе — кусок страницы в светлой теме внутри тёмной.
- Блог (`/blog`): отдельный раздел со своим меню (слева с 990px, на телефоне — строка чипов), пока заглушка; пункт «Блог» нижнего меню ведёт на него.
- Окно быстрого доступа: страница под ним размыта и затемнена, при смахивании листа размытие тает вслед за пальцем (как в ozon/stocks); мягкий оттенок вверху листа, строка «Вы здесь», страницы справки — группами, как списки настроек iOS.
- «Цвета»: конструкторы наверху страницы; новый «Конструктор стиля» — цвет, стиль (залитый, мягкий, контур, прозрачный), элемент (кнопка, метка, сообщение, карточка), «ярче при наведении», «Случайный», код HTML или JSX, контраст текста в обеих темах; вместо стандартного `<select>` — свой выбор цвета с образцами (вкладки «Смысловые» и «Палитра» 14 × 11), выезжает на пружине.
- «Токены» (`/docs/scss/tokens`): что такое токен, какие классы получаются, тени 1–12, скругления, песочница движения (пружины рядом с обычными кривыми, сдвиг / масштаб / поворот, длительность), градиенты, генератор своего токена (имя + цвет в двух темах → SCSS и классы), дерево файлов.
- «Тёмная тема»: песочница (кусок интерфейса в светлой, тёмной или системной теме), что меняется (токены двух тем рядом), подключение без мигания для Next.js, React и HTML, тема системы, вариант `dark:`, панель браузера, проверка.
- «Меню» нижнего меню — отдельная страница `/menu` (пока все разделы сайта карточками); окно быстрого доступа открывает кнопка в шапке.
- Шапка: после прокрутки вверху экрана проявляется градиент цвета фона (90px) — текст плавно уходит под шапку.
- Окно быстрого доступа: при прокрутке списка у шапки окна тень и мягкий градиент, строка «Вкладка — …», отступы просторнее.
- «Текст» (`/docs/scss/text`): конструктор (готовые наборы, размер, интервал, начертание, высота строки, цвет, выравнивание, обрезка, заглавные, свой текст) и примеры — шкала размеров, начертание, высота строки, интервал и регистр, цвет текста, обрезка и перенос, адаптивный размер, моноширинный шрифт и цифры одной ширины, размер текста на сайте.
- «Отступы» (`/docs/scss/spacing`): конструктор со схемой как в инструментах разработчика (внешний отступ, внутренний одинаковый или по осям, промежутки, направление, число детей) и примеры — шкала, отступы по сторонам, `mx-auto` и отрицательные, `gap`, ширина и высота, ограничения `max-w`, отступы под экран.
- «Тёмная тема»: конструктор переключателя темы (иконка с анимацией как в шапке, ползунок, три кнопки со «Системой», список; анимация и подписи; код для Next.js / React или HTML + JS) и установка «как на этом сайте» вкладками Next.js 16 · React · JavaScript · jQuery, лучшие приёмы 2026.
- Окно быстрого доступа: вкладки «На странице» (разделы линией с номерами, «вы здесь») и «Меню справки» (страницы плитками в две колонки), края списка плавно гаснут сверху и снизу.
- Платформа справки: вверху левого меню (и в окне быстрого доступа на телефоне) — Next.js, React, Node.js или HTML/CSS; выбор запоминается, установка показывает шаги под неё, конструкторы — код в JSX или HTML, «Тёмная тема» — нужную вкладку. Группа «Стеки» убрана.
- Готовый CSS для проектов без сборки: `npm run dist` → `dist/rendit-ui.css` (всё целиком: стили RenDit SCSS и 3 000+ классов RenDit Code — шкала отступов и размеров, все цвета, брейкпоинты, состояния) и сжатый `dist/rendit-ui.min.css`; с каждой версией — на CDN jsDelivr.
- «Обновления» (`/docs/releases`): все версии из CHANGELOG.md — что нового, дата и «Скачать» у каждой; карточка «Скачать RenDit UI» (архив, CDN, GitHub) — там же и на установке. В шагах установки для CSS и HTML — готовый файл из архива или строка CDN вместо «соберите один раз».
- Выпуск версий: `npm run release -- X.Y.Z` (CHANGELOG, package.json, готовый CSS, коммит и тег), GitHub собирает релиз с архивом `rendit-ui.zip` и CSS (`.github/workflows/release.yml`); проверка каждого пуша (`ci.yml`); `RELEASING.md`, `LICENSE` (MIT).

### Изменено
- Смена страниц: страница проявляется прозрачностью — без накладки цвета фона, из-за которой при переходах каждый блок на миг становился прямоугольником цвета фона (в тёмной теме — чёрным).
- UI-компоненты переехали в `src/components/ui`: окно быстрого доступа (`QuickNav`), переключатель темы, поиск, 3D-карточка (`Tilt`).
- Нижнее меню: Главная · **Справка** (ведёт на установку, выбрана во всём `/docs`) · **Блог** (пока без страницы) · **Меню** (открывает быстрый доступ). Иконки Boxicons: в ряду контурные, в линзе — залитые. Нажатие на уже выбранный пункт — как таб-бар iOS и Android: со страницы раздела — в его начало, в начале — плавно наверх.
- Цвета: фон светлой темы — `gray-50` (#fafafb) вместо белого, белые карточки на нём мягче; боковое меню справки — выбранный пункт белой карточкой.
- Шапка — сетка `1fr · auto · 1fr`: вкладки справки ровно по центру, с открытым поиском сдвигаются, но не наезжают на поле.
- Боковое меню справки длиннее экрана прокручивается само.
- Смена страниц без View Transitions: на время перехода браузер рисовал снимок страницы поверх стеклянных шапки и нижнего меню — меню пропадало, дёргалось и теряло размытие.
- Нижнее меню всегда на экране; при загрузке и перезагрузке выезжает снизу на пружине — только transform, без прозрачности у предков стекла (раньше блюр включался рывком в конце); быстрое меню — следом.
- Шапка: ссылки по центру убраны; логотип на главной плавно поднимает страницу наверх. Прокрутку отслеживает один встроенный скрипт (`Header/scroll-state.ts`), компонент `ScrollFlag` удалён.
- Размер шрифта: над цифрами подпись «Размер шрифта на сайте, px», цифры 13…18 — каждая своим настоящим размером.
- Шапка «Две таблетки» (вариант 13 с `/header`): наверху прозрачная; после прокрутки логотип с названием и кнопки остаются на местах в стеклянных таблетках (blur 12, shadow-7), надпись, версия и меню уходят. Ссылки ведут на страницы, текущая подсвечена цветом надписи «UI»; логотип — ссылка на главную. «Прожектор» — на таблетках.
- (было до «Двух таблеток») Шапка «Динамический остров»: при прокрутке вниз резко, но плавно, на пружине, сжимается в остров (логотип, версия, поиск) — меню, тема и «Начать» уходят. Переключается по порогу прокрутки с гистерезисом (`data-scrolled` на `<html>`), а не вместе с прокруткой: шапка не застревает на полпути. «Прожектор» — тусклое пятно света и кромка за курсором (только мышь).

- База: ссылки и кнопки наследуют цвет (без `opacity: 0.8` из ReluxCode), видимый фокус только с клавиатуры.

### RenDit Code
- Классы генерируются из исходников по требованию, числа — в пикселях.
- Токены читаются из SCSS: каждая переменная-цвет — класс `bg-*`, `text-*`, `border-*` …; `--shadow-*`, `--radius-*`, `--gradient-*` — свои классы.
- Прозрачность `/50` для любого цвета через `color-mix`.
- Варианты: состояния, брейкпоинты (`md:`, `max-md:`, `min-[…]:`), контейнерные запросы (`@md:`), `dark:`, `group-*`, `peer-*`, `aria-*`, `data-*`, `has-*`, произвольные `[&…]:`.
- Каскад считает движок: сокращённые свойства раньше развёрнутых, брейкпоинты по возрастанию, `active` сильнее `hover`.
- Сетка: `col-N`, `col`, `col-auto`, `offset-N`, `gutter-N`; CSS Grid: `grid-fill-N`, `grid-fit-N`.
- Наблюдение за файлами: пересборка за миллисекунды, CSS пишется только при изменении.

### Удалено по сравнению с ReluxCode
- Анимации (`float`, `hover-line`, `tr-*`), проектные стеклянные тени, номерные цвета `bg-1…6`, `.skip-link`, `.scroll-container`.
- Пустые заготовки `interactions/`, `motion/`, `responsive/`, `utilities/`, `layout/_flex` — эти классы генерирует движок.
